PHUMA

机器人全身轨迹

把人体动捕与视频中的动作做物理筛选，再映射到 G1、H1-2。拿到的是机器人每一帧应处于什么姿态。

Pipeline · 原工作流程概览
  1. 原始人体动作动捕数据 / 视频提取
  2. 物理质量筛选筛除跳变、悬浮等问题
  3. PhySINK 重定向生成 G1 / H1-2 轨迹
  4. 策略学习与跟踪模仿训练、仿真 / 真机验证
原工作创新点
  1. 物理约束重定向：把关节与接触约束纳入人体到机器人的动作映射，减少脚滑、悬浮和穿透。
  2. 物理质量筛选：在重定向前筛除不合理动作，提高后续模仿学习的数据质量。
主要格式
NPY
根部位置、旋转四元数、各关节角和帧率；本批样本为 30 Hz。

我们先做最先做 G1 动作跟踪与清洗前后对照，兼容 H1-2。

BONES-SEED

带标签的人体动作库

光学动捕记录的走路、舞蹈、日常活动等全身动作，配有语言描述和时间分段；同时提供人体骨架与 G1 版本。

Pipeline · 原工作流程概览
  1. 光学动作采集Vicon 记录人体动作
  2. 动作表示转换SOMA 人体 / G1 机器人
  3. 整合语义标签动作描述、时间分段、属性
  4. 发布动作库BVH / CSV 与配套元数据
原工作创新点
  1. 语义化动捕动作库：把大量光学动捕动作与语言描述结合，支持按语义检索和生成动作。
  2. 细粒度时间分段：为动作片段提供时间边界和语义标签，便于学习长动作的组成与顺序。
  3. 多种动作表示：同时提供 SOMA 人体与 G1 轨迹，便于跨本体适配与复用。
主要格式
CSV / BVH
CSV 存 G1 根部姿态与 29 个关节；BVH 存 SOMA 骨架及动作。
Parquet / JSONL
动作属性、语言描述与时间分段。动作约 120 Hz，需统一单位与坐标。

我们先做在 PHUMA 基线跑通后扩充动作；研究人体到 G1 的适配、动作检索和语言条件生成。

Humanoid Everyday

真实机器人操作记录

人遥操作 G1 / H1 完成开柜门、拿物品、使用工具等任务时，记录机器人的视觉、状态和动作。

Pipeline · 原工作流程概览
  1. 人类遥操作头部与手部输入
  2. G1 / H1 执行机器人完成真实任务
  3. 多模态记录视觉、深度、触觉、状态 / 动作
  4. 任务整理与发布语言标签、片段、LeRobot 格式
原工作创新点
  1. 扩展真实任务覆盖：覆盖移动操作、工具使用和人机交互，拓宽人形机器人操作学习的场景。
  2. 多模态遥操作记录：同步采集视觉、深度、触觉、状态与动作，为感知到控制的联合学习提供数据。
主要格式
Parquet + MP4
本批采用 LeRobot v2 格式：表格存状态、动作和时间戳，视频存 RGB；约 30 Hz。
JSON / JSONL
任务与片段信息；数据还包含深度、点云、IMU 和触觉等字段。

我们先做做“看见什么 → 执行什么动作”的操作模仿学习，以及视觉与机器人状态对齐。

EgoDex

第一视角手部操作

人佩戴 Apple Vision Pro 做折衣服、系鞋带等桌面任务。视频配有头部、上身、手腕和手指的三维姿态。

Pipeline · 原工作流程概览
  1. Vision Pro 采集第一视角操作视频
  2. 同步姿态估计ARKit 跟踪上身与手指
  3. 逐帧配对与标注视频、位姿、置信度、语言
  4. 数据发布与评测MP4 / HDF5、轨迹预测基准
原工作创新点
  1. 规模化视频与手姿配对：利用头显同步记录第一视角视频和三维手指姿态，覆盖多样的精细操作。
  2. 手部轨迹预测基准：提供模仿学习基线与评价指标，支持比较手部动作预测能力。
主要格式
MP4 + HDF5
一段视频对应一个标注文件；30 Hz、1080p。HDF5 存逐帧 4×4 位姿矩阵、置信度、相机内参与语言。

Xperience-10M

第一视角多模态记录

同步记录人做事时多台相机看到的画面，以及深度、身体和手部动作、IMU 与文字描述。图中为公开的手冲咖啡样例。

Pipeline · 原工作流程概览
  1. 多传感器采集多相机视频 / 音频、IMU
  2. 几何与运动标注深度、位姿、全身 / 手部
  3. 时间与语义整合设备时间戳、分层语言
  4. 按片段打包多路 MP4 + annotation.hdf5
原工作创新点
  1. 多模态时空同步：统一多视角视频、深度、相机位姿、全身 / 手部动作与 IMU，连接场景几何和人体行为。
  2. 分层语言标注：用任务、子任务、动作与交互等层级描述连续过程，支持动作和任务语义的联合研究。
主要格式
多路 MP4 + HDF5
完整片段通常为 4 路鱼眼和左右双目视频，配 annotation.hdf5。
HDF5 内部
深度、相机位姿、52 个身体关键点、每手 21 个关键点、IMU 与分层文字；实际有效字段需逐段检查。

我们先做做多传感器时间对齐、信息缺失与补全、手和物体的交互理解；转成 G1 控制参考还需适配。
